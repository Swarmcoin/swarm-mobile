# App Review information

`notes.txt` describes the mainnet app and its review steps. The owner must
provide these four files before App Review information can be saved:

| File | Required information |
| --- | --- |
| `first_name.txt` | Reviewer support person's first name |
| `last_name.txt` | Reviewer support person's last name |
| `email_address.txt` | Email read during review |
| `phone_number.txt` | Phone number in international format |

Apple requires these fields even for an API update limited to review notes.
The internal TestFlight group can receive builds independently of this form.

Any funded review wallet must be created for App Review. Keep recovery
phrases outside the repository.
